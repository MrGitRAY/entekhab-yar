# انتخاب‌یار

وب‌اپلیکیشن فارسی برای شناخت مسیر تحصیلی داوطلبان تجربی و ریاضی، با پیشنهاد اولیه خانواده‌ها و رشته‌های دانشگاهی.

**وضعیت: مرحله ۵ — Matching، گزارش وب و تولید PDF ساخته شده‌اند.** برنامه به Supabase متصل و جریان شروع آزمون در محیط محلی راه‌اندازی شده است. نتیجه‌ها اکتشافی‌اند و ابزار هنوز اعتبارسنجی روان‌سنجی نشده است.

## تصمیم‌های پایه

| موضوع | تصمیم |
| --- | --- |
| رابط و سرور | Next.js App Router + TypeScript، در یک برنامه |
| داده و هویت | Supabase PostgreSQL + Auth با دسترسی محدود به صاحب آزمون |
| استقرار هدف | Vercel |
| تجربه کاربر | فارسی، راست‌به‌چپ، طراحی از موبایل |
| منبع محتوای نسخه اول | پنج فایل JSON نسخه‌دار در `data/` |
| موتور پیشنهاد | محاسبات قطعی و توضیح‌پذیر در سرور، بدون وابستگی به مدل زبانی |
| گزارش | یک نتیجه ذخیره‌شده با دو نمایش دانش‌آموز و مشاور؛ تولید PDF داخلی |
| توسعه آینده | ورود Excel از طریق تبدیل و اعتبارسنجی، بدون تغییر موتور پیشنهاد |

## ساختار فعلی

```text
Thesis/
├── docs/                       مستندات و متن درخواست
├── data/                       پنج JSON نسخه‌دار و قابل اعتبارسنجی
├── src/
│   ├── app/                    صفحه شروع، فرم، گزارش وب و APIهای مراحل ۳ و ۴
│   ├── components/             اجزای مشترک رابط
│   ├── features/
│   │   ├── assessment/         فرم و وضعیت پاسخ‌ها
│   │   └── results/            نمایش نتیجه و گزارش تفصیلی وب
│   ├── domain/
│   │   ├── assessment/         مدل سؤال، پاسخ و امتیازدهی
│   │   ├── matching/           تطبیق خانواده و رشته
│   │   └── reporting/          قرارداد محتوای گزارش
│   ├── server/
│   │   ├── services/          هماهنگی عملیات و کنترل دسترسی
│   │   └── repositories/      قرارداد ذخیره و بازیابی
│   └── infrastructure/       
│       ├── catalog/           خواندن و اعتبارسنجی JSON
│       ├── supabase/          اتصال و پیاده‌سازی ذخیره‌سازی
│       └── pdf/               تولید فایل PDF فارسی از snapshot گزارش
├── supabase/migrations/       طرح SQL و کنترل دسترسی
├── supabase/seed.sql          بارگذاری نسخه آزمایشی کاتالوگ
├── scripts/catalog/           اعتبارسنجی و تولید seed از JSON
├── scripts/import/            تبدیل Excel در توسعه بعدی
├── public/fonts/              فونت آزاد فارسی رابط و PDF
└── tests/                     آزمون‌های معنادار مراحل اجرایی
```

پوشه‌های رزروشده باقی‌مانده با `.gitkeep` نگهداری می‌شوند. برای بررسی کاتالوگ `node scripts/catalog/validate.mjs` و برای بازسازی فایل بارگذاری `node scripts/catalog/build-seed.mjs` اجرا می‌شود. نسخه وابستگی‌های برنامه در `package-lock.json` تثبیت شده است.

## اجرای محلی

```bash
npm install
npm run dev
```

سپس `http://localhost:3000` را باز کنید. برای اجرای آزمون اصلی، متغیرهای محلی را طبق [راهنمای استقرار](docs/deployment.md) در `.env.local` تنظیم کنید و migrationها و seed را روی پروژه Supabase اجرا کنید. بدون تنظیم Supabase، فرم با برچسب «پیش‌نمایش» اجرا می‌شود و پاسخ‌ها را تا بسته‌شدن تب در همان مرورگر نگه می‌دارد.

بررسی‌ها: `npm run typecheck`، `npm run build` و `npm test`. اعتبارسنجی داده: `npm run validate:data`. نمونه‌های ساختگی قابل بازتولید: `npm run examples`.

وزن رتبه‌بندی فعلی فقط روی شش رغبت RIASEC است؛ سایر محورهای خودگزارشی در گزارش توصیفی می‌مانند. پروفایل هدف از داده O*NET® 31.0 ساخته شده، اما نگاشت شغل به رشته فرض تحریریه‌ای است و پذیرش ایران را تأیید نمی‌کند. نسخه `0.1.0-pilot` در `data/releases/` حفظ شده است.
