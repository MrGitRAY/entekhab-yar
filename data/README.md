# داده نسخه‌دار

نسخه فعال `0.2.0-pilot` با schema 2 شامل پنج JSON است: ۶۴ رکورد سؤال، ۶۰ سؤال در هر گروه، ۱۰ خانواده و ۴۳ رشته/مسیر. همه محتوای سنجش هنوز پایلوت است. نسخه قبلی و seed آن در `releases/0.1.0-pilot/` حفظ شده‌اند.

پروفایل هدف شش‌محوری از فایل رسمی `sources/onet-31.0/career_interest_types.json` به دست می‌آید. provenance شامل URL، تاریخ دریافت، نسخه، SHA-256 و مجوز است. مقادیر خام و کد شغل‌های استفاده‌شده داخل majors نگهداری می‌شوند؛ برای محاسبه به اینترنت نیاز نیست. پروفایل ۲۶محوری فرضی سابق حذف شده است.

هر مسیر `mapping.rationale` و `editorial_pending_expert_review` دارد. `admissionStatus: unverified` همچنان یعنی عنوان/گروه پذیرش ایران بررسی نشده است. `kind: pathway` باید به صورت «مسیر تخصصی» نمایش داده شود. انتخاب شغل و میانگین‌گیری از آن، فرض تحریریه‌ای محصول است.

اعتبارسنجی: `npm run validate:data`. بازسازی seed: `node scripts/catalog/build-seed.mjs`. اسکریپت `review-stage4.mjs` بازسازی یک‌باره همین انتشار از آرشیو نسخه قدیمی و فایل رسمی ثابت است؛ ابزار ویرایش انتشار بعدی نیست. برای تغییر بعدی نسخه تازه بسازید و انتشار seal‌شده را تغییر ندهید.

اجرای اصلی محاسبات روی سرور است. پیش‌نمایش محلی برای نمایش، کاتالوگ را در مرورگر استفاده می‌کند و هیچ داده عملیاتی معتبری در سرور نمی‌نویسد. [بازبینی علمی](../docs/scientific-review.md)، [فرمول‌ها](../docs/matching-stage4.md) و [قرارداد دیتابیس](../docs/data-and-database.md) مرجع‌اند.
